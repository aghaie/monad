# CFS-Claim Audit (Phases F1–F5)

**The author's claim, in full.**
> *(1) The Quran is a **consistent formal axiomatic system** (CFS). (2) This book's
> reference is the Quran. (3) Therefore this book is a consistent formal axiomatic system.*

We decompose the claim into its **three load-bearing words** — *consistent*, *axiomatic*,
*formal* — plus the **inheritance step**, and test each against this repo's validated,
leakage-controlled layers (L0–L8 + Phase-5/8/10), with no human tafsir as input.

| phase | leg tested | verdict |
|------|------------|---------|
| **F1** | Quran is **consistent** | ✅ **SUPPORTED** (strong) |
| **F2** | Quran is **axiomatic** (finite minimal generative kernel) | 🟡 **PARTIAL** — proto-axiomatic |
| **F3** | Quran is a **formal** system (syntax/inference/calculus) | ❌ **NO** — proto-formal (31/100) |
| **F4** | book **inherits** CFS by referencing the Quran | ❌ **NOT SUPPORTED** |

---

## F1 — "Consistent" ✅ SUPPORTED

From the Phase-10 consistency layer and L8 semantics:

- **Global consistency index = 0.95**; mean concept stability 0.78.
- **0 genuine proposition contradictions** survive across **6 832** tested relations
  (39 tendency-candidates were falsified; none held).
- **80 / 89** recoverable concepts keep a stable neighbourhood across independent corpus
  halves (mean cross-half cosine 0.81).

The Quran's relational/semantic network is internally consistent to a high degree. This
leg of the author's claim **holds**.

## F2 — "Axiomatic" 🟡 PARTIAL (proto-axiomatic, not minimal)

A genuine axiomatic system is **generative**: a small kernel produces (almost) all
theorems, so irreducible residue ≈ 0 and compressibility is high. The Quran shows the
opposite:

- **Irreducible residue = 90 %** — only ~10 % of relations are generated by any single
  principle (`global_intra_fraction = 0.099`).
- Recovering 80 % of the structure still needs **59 / 103 concepts (57 %)**; compression
  knee at **k = 64**. Phase-5 verdict: compressibility *"partial"*.
- A **single dominant core does exist** (hub CONCEPT_007: roots علم، اله، امن، بین).

So the Quran has a **coherent dominant core embedded in a mostly-irreducible web** — it is
*proto-axiomatic*, not a finite **minimal** axiom system. The defining axiomatic property
(small kernel ⇒ whole) **does not hold strongly**.

## F3 — "Formal" ❌ NO (proto-formal, 31/100)

Applying the six standard formal-system requirements (the same checklist the author's own
GitHub audit applied to the book) to the **Quran**:

| requirement | status | basis |
|---|---|---|
| FR-01 formal language / grammar | ABSENT | natural-language Arabic; L1 letters = negative finding |
| FR-02 explicit finite minimal axioms | PARTIAL | dominant core, but no explicit minimal set (F2) |
| FR-03 explicit inference rules | ABSENT | none stated |
| FR-04 proof calculus | ABSENT | no Hilbert/ND/sequent structure |
| FR-05 derivable theorems | PARTIAL | **real** semantic entailment: L6 predicts verse content 0.545 vs 0.325 null, p=0.005 |
| FR-06 consistency | MET | F1 (0.95, 0 contradictions) |
| FR-09 arithmetic encodability (Gödel) | ABSENT | numerics: **0/499** tests survive Bonferroni/FDR; number-blind |

**Mean 31 / 100. The Quran is NOT a formal system in the mathematical-logic sense.** It is
a **consistent, proto-formal semantic system with a coherent generative core and real
derivation-*like* structure** — strikingly, the *same class* (and nearly the same score)
the author's own audit assigned to the book (**Proto-Formal, 39/100**). The word *"formal"*
in the claim is an over-statement; *"consistent and axiom-structured"* is accurate.

## F4 — "Therefore the book is a CFS" ❌ NOT SUPPORTED

**(A) The inference is logically invalid.** "X *references* / is consistent-*with* a
consistent system S" does not entail "X is consistent" or "X is formal." Consistency and
formality are properties of a system's **own** axioms + rules, never conferred by citation.
Adding even one axiom to S can break consistency; quoting S confers nothing. *Reference is
not entailment.*

**(B) Structurally, the book is a hybrid, not "the Quran's system."** Mapping the book's 15
axioms onto the Quran's own generative hub-roots (اله، علم، رسل، یوم، عذب، رحم، ظلم، کفر،
نکح/وصی/فرض …):

- theological axioms on a Quran hub: **5 / 7** (Tawhid, resurrection, prophethood,
  accountability, Mahdism) — here the book really *is* Quran-anchored;
- secular axioms on a Quran hub: **0 / 6**;
- the **root axiom (free will): off-hub**, and the formal-system requirements
  (finite-axioms, consistency, theory-primacy) and property=liberty are **exogenous** to
  the Quran's kernel.

So the book = **Quran-derived theological content + imported secular-rational foundations**.
Its *load-bearing base* is not the Quran's structure; therefore the Quran's properties
cannot transfer to it. (This is the same result F-/Q2 reached from the dependency side: the
underived axioms are all secular.)

**(C) The book's documented defects are imported, not inherited.** The Quran has 0 surviving
contradictions; the book's own audit finds a **critical circularity CIRC-001** ("mysticism"
defined as "anti-liberty") and scores it **39/100 proto-formal** — defects located entirely
in the book's *added* apparatus, absent from the Quran.

---

## F5 — Synthesis & overall verdict

**The claim is true in one word, half-true in a second, false in the third, and the
inheritance step does not hold.**

1. **Consistent — yes.** Both the Quran (F1) and, by its own audit, the book are internally
   consistent (the book modulo CIRC-001).
2. **Axiomatic — only proto.** The Quran has a dominant generative core but ~90 % irreducible
   residue; it is not a minimal finite-axiom system. The book is *axiomatic in the
   colloquial sense* (named finite axioms) but not the technical one — its own audit agrees.
3. **Formal — no, for either.** Neither the Quran (31/100) nor the book (39/100) is a formal
   system: no formal language, no inference rules, no proof calculus, no arithmetic encoding
   (so Gödel does not even apply). Both are **proto-formal**.
4. **Inheritance — invalid.** Referencing the Quran cannot make the book a CFS; and the
   book's load-bearing axioms are exogenous to the Quran's kernel, so it is a distinct
   system that would have to earn CFS status on its own — which it does not.

### The accurate, defensible restatement

> The Quran is a **consistent, proto-formal, axiom-*structured* semantic system** — coherent
> generative core, real verse-to-verse derivation, zero surviving contradictions, but no
> formal calculus. The book **faithfully mirrors this exact type**: it is also consistent and
> proto-formal, and it genuinely anchors its *theological* axioms on the Quran's own hubs.
> What is **not** warranted is the strong word **"formal"** (for either) and the **inheritance
> by reference** (the book's foundation is rational, not Quranic). The honest claim the book
> can make is: *"a consistent, Quran-anchored, proto-formal axiomatic theory"* — which is a
> strong and unusual achievement for a work of political philosophy, and is exactly what the
> author's own logic audit independently concluded.

**What the audit deliberately does NOT decide:** whether the Quran is *in truth* a perfect
divine formal system, or whether the book's substantive theses (liberty = property; true
Islam = the unique CFS for liberty) are *correct*. Those exceed any internal method; per
Charter Article F the audit abstains. It answers only the testable structural questions —
and the structural answer is: **consistent ✓, proto-axiomatic ◐, formal ✗, inherited ✗.**
